## 交付范围与原则

继续采用 C17，可静态交付。保持无 root / 无特权容器 / 无 user namespace 的基本执行模式；增强能力按内核、LSM 和部署权限实际探测，显式请求但无法建立保护时拒绝启动。cgroup 委派等部署要求单独列出，默认 Docker 不具备的权限不能假装存在。所有新功能同时更新 CLI、JSON 契约、设计、依赖、示例和实测记录。

域名授权明确区分 DNS 地址快照与应用层域名身份。动态监管不允许通过检查可变指针后 CONTINUE 来授权敏感操作；需要监管者使用自己固定的参数执行或内核继续负责最终授权。工作区隔离可采用无需挂载的物理快照，必须明确其与 overlayfs 按需 COW 的差异。审计区分 syscall 请求、策略决定、实际执行结果，不能把意图日志当成功访问日志。
