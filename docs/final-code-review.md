| 编号 | 原行为与影响 | 最终修复结论 |
|---|---|---|
| F1 / P1 | 原调用方在复制/DNS等准备中退出后，CLI可能被收养并仍启动业务 | 准备前固定原调用方TGID pidfd；guardian先终止并等CLI退出再清理；各交接/启动屏障及运行期检查同一身份 |
| F2 / P2 | 根目录chmod/mtime改变会导出，但diff未记录 | baseline/tree manifest包含根条目`.`，保持复制条目/字节预算不计根的语义 |
